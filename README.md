# 音芽 · 音乐创造课堂

一个面向中学生的 Node.js 音乐创作课堂最简版本。老师创建课堂后分享六位班级码；学生加入后可以查看和提交任务、举手，课堂会实时显示在线人数和作品。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm ci
npm start
```

浏览器打开 `http://localhost:3000`。老师先创建课堂，再把班级码分享给学生。课堂和作品保存在 `data/classrooms.json`；在线人数和举手状态根据当前连接实时计算。默认端口为 `3000`，也可以通过 `PORT` 修改；持久化文件路径可通过 `CLASSROOM_DATA_FILE` 修改。

## 功能

- 老师可创建带主题的课堂并获得随机班级码。老师的课堂凭据保存在当前浏览器中，以便刷新后重新连接。
- 学生用班级码和名字加入课堂，无需注册账号。
- 老师发布开放式旋律创作任务；学生提交或更新作品，老师可以查看提交内容。
- 学生可以举手或放下手。在线人数、举手队列、任务和提交内容会通过 Socket.IO 实时更新。
- “灵感小芽”提供内置的音乐创作引导：根据学生的想法给出调式、音符、节奏和循序渐进的编创练习，不需要外部 API 密钥。当前版本使用本地音乐理论与提示模板，不会把学生输入发送给外部 AI 服务。

这是适合课堂原型和小规模试用的单进程版本。班级数据保存在单个 JSON 文件中，服务器重启后保留；部署多个应用实例前，需要替换为共享数据库和 Socket.IO 适配器。班级码不是身份认证；不要在课堂中收集不必要的个人信息。
