# 豆芽AI｜音乐创造教育平台

面向中小学音乐课堂的 Node.js 网页原型，围绕创造性聆听、创造性表演、即兴编创和音乐创作，串联教师备课、课堂实践与课后回顾。平台对应课题《人工智能赋能青少年音乐创造力培养的机制剖析与模式探索》（课题编号：JSJY2025015）。

## 本地运行

要求 Node.js 20 或更新版本。

```sh
npm ci
npm start
```

打开 `http://localhost:3000`。开发时可运行 `npm run dev`。运行数据保存在 `data/douyai.json`；可通过 `DOUYAI_DATA_FILE` 指定其他路径。`data/` 已加入 `.gitignore`。

## 账号与班级

- 登录入口分为教师、中小学生、职前教师，服务端按身份校验可执行的操作。
- 首次使用请在对应入口注册独立账号并设置至少 10 位密码；没有全体共用的默认密码。登录后可在账户设置中修改密码。
- 教师创建班级时生成长期有效的专属班级码。学生可在注册时选班并输入班级码，也可登录后加入其他班级。
- 教师开始实时课堂后会另行生成临时课堂码。学生先加入班级，再用临时码进入当次课堂；课堂码与班级码用途不同。

## 功能

- 教师工作台：班级管理、课程活动设计、教材知识库、实时课堂、任务发布和过程观察报告。
- 学生工作台：班级与课堂任务、举手和在线状态、作品集、能力趋势，以及同一页面内切换的聆听、表演、即兴、创作四个实践模块。
- 音乐实践：浏览器音频播放、麦克风本地录音、八步旋律编创、多轨片段编辑、MIDI 文件导入/导出（取决于浏览器对 Web MIDI 的支持）。
- 豆芽AI：提供循序渐进的音乐创作对话。未配置大模型时使用站内引导逻辑；也可配置兼容 DashScope 的 Qwen Plus 服务。
- 教材知识库：教师或职前教师可添加教材摘录，也可上传 `.txt`、`.md`、`.csv`、`.json` 文件（单文件上限 2 MB）。平台会提取标题、单元、学段和音乐要素等索引，供课程设计和 AI 辅导参考。收到正式教材文件后，应以经审核的知识库内容补充或替换示例条目。

## AI 配置

默认不向外部模型发送学生对话。若学校已完成相应的数据治理与告知流程，可在运行环境中设置 `MUSIC_AI_API_KEY`，并可选设置 `MUSIC_AI_MODEL`（默认 `qwen-plus`），启用 DashScope 兼容接口。启用后，学生输入的提问及必要的对话上下文会发送到 DashScope；不要输入学生姓名、联系方式或其他可识别信息。

## 当前原型的数据边界

课堂状态通过 Socket.IO 实时同步，账号、班级、作品和记录存放在本地 JSON 文件中，适用于演示与小规模试用。多人并发或正式学校部署前，应将文件存储替换为数据库并设置备份、保留期限、监护人告知与机构账号审核；目前的创造力维度是过程性观察提示，不用于给学生排名或形成诊断结论。
